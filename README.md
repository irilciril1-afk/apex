# Apex

Сайт автосалона: 10 машин, отдельная страница у каждой, подбор по кузову, цене и состоянию, форма записи на просмотр.

Открыть: `index.html` (один файл, фото внутри). Для GitHub Pages включите Pages для ветки `main`, папка `/ (root)`.

Исходники: `src.html` (шаблон), `build.py` (данные машин и сборка), `img/` (обработанные фото).
Форма пока проверяет поля только в браузере и никуда не отправляет данные.
